# Security policy

## Supported versions

Security fixes are provided for the most recent Goodreads Library Manager release.

## Reporting a vulnerability

Please do not open a public issue for a vulnerability. Use GitHub's **Security > Report a vulnerability** flow for this repository so details can be reviewed privately.

Include the extension version, browser version, reproduction steps, and expected impact. Do not include Goodreads credentials, cookies, security tokens, library exports, or other private data.
